# Global Superstore 2016 Dataset

This repository contains the Global Superstore 2016 Excel dataset for data analysis and visualization. It is suitable for exploratory analysis, reporting, dashboards, and portfolio projects.

## Contents

- `global_superstore_2016.xlsx` — source dataset in Microsoft Excel format

## Suggested analysis

- Sales, profit, and order trends over time
- Performance by market, region, country, category, and sub-category
- Customer and product purchasing patterns
- Shipping and order-processing metrics

## Getting started

1. Download or clone this repository.
2. Open `global_superstore_2016.xlsx` in Microsoft Excel or a compatible spreadsheet application.
3. Import the data into your preferred analysis or visualization tool.

## Notes

- The dataset is kept in its original Excel format.
- Please review the dataset's source terms before reusing or redistributing it.
